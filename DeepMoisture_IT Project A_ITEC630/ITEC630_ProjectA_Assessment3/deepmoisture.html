Data & ML Pipeline

From Raw Sensor Data
to Farm Forecasts

A five-stage automated pipeline — from SILO/TERN API ingestion through to Streamlit dashboard delivery — built with full DVC version control and reproducibility.

🛰️
Phase 01
Data Ingestion
Automated extraction via SILO, TERN & BoM APIs. Historical meteorological data from 1889 onwards. DVC versioned.
🔬
Phase 02
EDA & Preprocessing
Exploratory data analysis, missing value imputation via forward-fill & interpolation. Temporal train/val/test splits to prevent data leakage.
⚙️
Phase 03
Baseline Models
ARIMA, XGBoost and LSTM trained on MDB data. KGE & RMSE benchmarks established to quantify AI model improvements.
🧠
Phase 04
Foundation Models
Chronos-2 & TimesFM 2.5 evaluated zero-shot then fine-tuned on agricultural domain. Google Colab Pro GPU compute monitored per sprint.
📊
Phase 05
Dashboard
Streamlit frontend with station selectors, interactive forecast charts, uncertainty bands, and <1% task failure rate target.
